# 排除表负例大杂烩

> 本用例把所有已知误报防护项（白名单/排除表/lookbehind/lookahead/引号掩码）集中在一份虚构工程规格片段中，断言全部零命中——防止排除表倒退的回归保险。

## 状态与 UI 术语（A5 不应报）

订单状态包含「待确认」和「已完成」；详情页有骨架占位与占位图，金额处显示 ¥xxx 价格示意；语音复读模板在用户未输入时展示「学你说：xxx」。
接口文档示例：POST /api/v1/orders，认证头 <domain>/<JWT>。

## 固定搭配与法定术语（B1 不应报）

平台定位是智能化平台，引导文案保持友好提示；产品设计遵循隐私友好与环境友好；AI 生成内容需带显著标识；规则随业务量增长逐步完善，验收标准持续完善中。

## 商务与等待语义（C3 不应报）

货款等回款后确认，审批等财务通知，操作等审核通过；请稍等，稍等一下，等我一下，我等一下；接口需保证幂等，不等价处理不生效；A 与 B 是等价条件；本次发布包含系列三项能力；同等条件下优等候选优先。

## 法规原文引语（C3 引号掩码不应报）

通知原文：「涉及支付、知识产权等事项按现有规定执行。」

## 工程承诺（C6/C7 不应报）

系统在 30 秒内完成初始化，数据写入与读取均为同步操作。
