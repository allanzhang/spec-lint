# 工程规格片段（不应产生机械误报）

## 订单状态
- 订单 DRAFT 待确认：客户下单后等待业务员确认；超 24h 只提醒。
- 已支付待确认：钱在路上，等财务在 ERP 登记到账后系统自动对上账。
- SYNC_FAILED：ERP 写回失败，可手工重试（幂等），不重复建单。

## 接口约定
- 基础路径 `https://api.<domain>/api/v1/mp`，请求头 `Authorization: Bearer <JWT>`。
- 取价中显示骨架占位；详情图加载失败显示占位图。
- 金额展示「合计 ¥xxx」以实时取价为准。

## 双轨模型
客户主数据分两类：ERP 权威字段（编码/名称/信用）SaaS 只读镜像；SaaS 扩展字段 SaaS 维护。
某订货平台一期建设；六类校验全部生效并给友好提示；SaaS 框架随一期主链路逐步完善。
