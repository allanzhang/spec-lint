# 智能推送中心 PRD（v0.3 草稿）

## 1. 项目背景与目标

当前 App 的推送点击率持续走低，用户反馈推送打扰严重。本期目标：

- 显著提升新用户的上手效率，让首周体验更流畅；
- 大幅提升推送点击率，整体提升用户满意度；
- 打造智能化、一站式的消息管理体验。

## 2. 目标用户

面向全体用户优化推送策略。

## 3. 功能范围

本期覆盖 3 个核心场景：

1. 新用户首日引导推送；
2. 流失用户召回推送；
3. 交易到账通知；
4. 活动营销推送；
5. 夜间免打扰模式；

支持微信、支付宝等支付方式的到账通知。推送渠道包括厂商通道、个推等等。

## 4. 功能需求

- 需要优化推送下发频控，避免打扰用户；
- 建议加强用户对推送权限的引导；
- 营销推送支持人群圈选，圈选规则 TBD；
- 推送点击率目标提升至行业领先水平；
- 不影响现有交易通知的到达率。

## 5. 排期

Q4 上线，开发周期两周。

## 6. 成功指标

- 推送点击率显著提升。
